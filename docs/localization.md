# Языки интерфейса / Интерфейстин тилдери

FirstCase поддерживает русский (`ru`) и кыргызский (`ky`). Кнопка выбора языка доступна до входа и внутри приложения. Выбор сохраняется в Drift на устройстве и остаётся после смены аккаунта. При первом открытии используется язык устройства: кыргызский для `ky`, русский для остальных языков.

При первом входе без сохранённого выбора принимается язык профиля. Сохранённый выбор устройства имеет приоритет и записывается в профиль через `PATCH /users/me`, чтобы Telegram-бот присылал уведомления на том же языке. При недоступности сети интерфейс переключается локально, а ошибка синхронизации показывается пользователю.

FirstCase орусча (`ru`) жана кыргызча (`ky`) иштейт. Тилди киргенге чейин да, колдонмонун ичинде да алмаштырууга болот. Тандоо түзмөктөгү Drift сактагычында сакталат жана аккаунт алмашканда өзгөрбөйт. Биринчи ачылганда түзмөктүн тили `ky` болсо кыргызча, калган учурда орусча колдонулат.

Сообщения интерфейса находятся в `frontend/lib/l10n/app_ru.arb` и `app_ky.arb`. Используется стандартный Flutter `gen-l10n`, типизированные `context.l10n` getters и методы с аргументами. Материалы пользователей — имена, описания задач, переписка, отзывы и названия файлов — отображаются в оригинале. Их нельзя подменять переводами интерфейса.

Интерфейстин билдирүүлөрү `frontend/lib/l10n/app_ru.arb` жана `app_ky.arb` файлдарында. Flutter `gen-l10n` типтештирилген `context.l10n` талааларын жана аргументтүү ыкмаларын түзөт. Колдонуучулар жазган ысымдар, тапшырмалар, каттар, пикирлер жана файл аттары түп нускасында көрсөтүлөт.

Для нового текста добавьте семантический ключ в оба ARB. Для переменных задайте `@key.placeholders` с типом. Для счётчиков используйте ICU plural: русский требует `one`, `few`, `many`, `other`, кыргызский — `other`. Даты форматируются по текущей локали; встроенные компоненты ForUI, Material и Cupertino используют штатные кыргызские делегаты установленного SDK.

Жаңы текст үчүн эки ARB файлына тең маанилүү ачкыч кошуңуз. Өзгөрмөлөрдүн түрүн `@key.placeholders` аркылуу көрсөтүңүз. Сандарга ICU plural колдонуңуз: орусча `one`, `few`, `many`, `other`, кыргызча `other`. Даталар учурдагы тилде көрсөтүлөт. ForUI, Material жана Cupertino компоненттери SDKдагы кыргызча котормолорду колдонушат.

```sh
cd frontend
flutter gen-l10n
flutter test test/localization_test.dart
cd ..
python scripts/check_localization.py
```

HTTP-запросы, включая загрузку и скачивание файлов, отправляют `Accept-Language`. Переключение языка сохраняет токен авторизации и обновляет категории и серверные ресурсы. Ключи локального кеша включают язык, поэтому русский кеш не используется как кыргызский ответ. Отсутствующий перевод интерфейса считается ошибкой сборки, проверки или теста; общего словаря, подменяющего произвольные строки, нет.

HTTP сурамдары, анын ичинде файлдарды жүктөө жана жүктөп алуу, `Accept-Language` жөнөтөт. Тил алмашканда кирүү токени сакталат, багыттар менен сервердик маалыматтар жаңыланат. Кештин ачкычы тилди камтыйт: орусча маалымат кыргызча жооп катары колдонулбайт. Интерфейстин котормосу жок болсо, текшерүү катаны көрсөтөт; каалаган текстти алмаштырган жалпы сөздүк колдонулбайт.
