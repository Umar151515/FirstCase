## Исправления надёжности и изоляции аккаунтов — 21 октября

- Реальные Telegram-права администратора сверяются с текущей конфигурацией при использовании существующего токена и при модерации другого пользователя. Повторный вход сохраняет выбранное в FirstCase имя профиля.
- Ответы с ошибками размера запроса, частоты запросов и внутренними ошибками сохраняют CORS для разрешённых источников и защитные заголовки. Некорректный `Content-Length` отклоняется; ответ 405 сохраняет `Allow`, а 429 — `Retry-After`, доступный браузеру.
- Повреждённый JPEG отклоняется с 422 до записи файла. Сохранённый QR остаётся закреплён за настройками чаевых даже при `enabled=false`; повторное использование разрешается после удаления QR из настроек.
- Первое сохранение настроек чаевых сериализовано по строке владельца. Отдельный PostgreSQL-тест одновременно выполняет восемь сохранений в независимых транзакциях. URL длиннее 2048 символов отклоняются с 422; реквизиты заблокированного владельца закрыты.
- В собственном каталоге остаются видны задачи, скрытые модерацией. Публичный каталог продолжает скрывать их.
- Запоздавший outbox worker больше не изменяет результат новой попытки доставки. Windows backup восстанавливает только сервисы, работавшие до резервного копирования; сценарии успеха и ошибки проверены с подменёнными Docker-командами. Alembic запускается текущим интерпретатором Python, некорректные значения локализации диагностируются без падения проверки.
- Flutter отбрасывает личные ответы и скачивания, пришедшие после смены аккаунта; поздний вход не восстанавливает сессию после выхода. Публичные категории и конфигурация загружаются независимо от смены токена. Offline-кеш не подменяет ошибки доступа. Сохранённые личные данные привязаны к владельцу между запусками приложения.

В последующих запусках подтверждённый владелец сохраняет свои черновики, смена владельца очищает личные записи.
- Содержимое каждой страницы получает ключ аккаунта без пересоздания GoRouter: открытые формы задачи и профиля не переносят введённые данные другому пользователю. Форма задачи ждёт завершения входа перед восстановлением черновика и отбрасывает устаревшую загрузку.

Flutter собирается в JavaScript: optional WASM dry-run отключён из-за JS interop зависимости flutter_telegram_miniapp 0.1.2. Это не отключает SQLite WASM Drift. Проверка в настоящем Telegram WebView, Safari и Firefox не выполнялась.
